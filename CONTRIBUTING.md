# Contributing to Omni Video Studio

We welcome contributions to expand styles, shot recipes, animation frameworks, and prompter formulas!

## Guidelines
1. **Zero Secrets**: Never commit API keys, personal access tokens, session cookies, or private credentials.
2. **Quality Standards**:
   - Motion Graphic styles must include prompt templates, design guidelines, and color palettes.
   - Code animation recipes must be tested and compile cleanly under Node.js / React / TypeScript.
   - Cinematic shots should specify exact focal lengths, camera trajectories, and lighting setups.
3. **Submit a Pull Request**:
   - Fork the repository.
   - Create a feature branch: `git checkout -b feature/new-style`.
   - Commit your additions: `git commit -m "Add new cinematic shot card"`.
   - Push and open a Pull Request.
